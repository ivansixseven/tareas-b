# Sistema de cine: estructuras de datos en memoria

Programa en Python que gestiona solicitudes de un cine usando una lista enlazada, una pila y una cola. No usa bases de datos ni SQL.

## Contenido
- `Nodo` y `ListaEnlazada`: lista enlazada propia (sin listas de Python). `agregar` inserta al final sin perder los nodos existentes.
- `Pila`: LIFO. `apilar` y `desapilar`, con control de pila vacía.
- `Cola`: FIFO. `encolar` y `desencolar`, con control de cola vacía. El método `mostrar` (reto individual) imprime los elementos que quedan en la cola.

## Datos de prueba
CI01: Sala 1; CI02: Sala 2; CI03: Sala 3.

## Ejecución
```
python main.py
```
